# Trocador de Cores 🌈
Este projeto é uma aplicação simples e interativa que permite trocar a cor de fundo da página ao clicar em um botão. A aplicação conta com duas versões:

1. Simple: Altera a cor de fundo com base em uma lista de cores predefinidas.
2. Hex: Gera uma cor aleatória no formato hexadecimal.


# 🚀 Funcionalidades
* Alterar a cor de fundo da página ao clicar em um botão.
* Exibir a cor atual na tela.
* Deletar livros da lista.
* Filtrar livros por título, autor e gênero.
* Suporte a duas formas de gerar cores:
  * Lista fixa de cores (Simple).
  * Cores geradas aleatoriamente no formato hexadecimal (Hex).


# 🖥️ Como Usar
1. Clone o repositório:

```bash
git clone https://github.com/analuisaabarbosa/trocador-de-cores.git
```
2. Abra o arquivo index.html no navegador ou Live Server para usar.
